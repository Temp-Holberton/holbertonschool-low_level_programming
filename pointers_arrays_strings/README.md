# C - Pointers, arrays and strings

This repository contains solutions for the advanced C programming tasks focusing on pointers, pointers to pointers, multi-dimensional arrays, and low-level memory manipulation.

## Tasks

* **0. memset** (`0-memset.c`): A function that fills the first `n` bytes of the memory area pointed to by `s` with the constant byte `b`.
* **1. memcpy** (): A function that copies  bytes from memory area  to memory area .
* **2. strchr** (): A function that locates a character in a string.
* **3. strspn** (): A function that gets the length of a prefix substring.
* **4. strpbrk** (): A function that searches a string for any of a set of bytes.
* **5. strstr** (): A function that locates a substring.
* **6. Chess is mental torture** (`7-print_chessboard.c`): A function that prints the chessboard.
* **7. The line of life is a ragged diagonal between duty and desire** (`8-print_diagsums.c`): A function that prints the sum of the two diagonals of a square matrix of integers.
