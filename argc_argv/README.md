# 0x0A. C - argc, argv
* **0. It ain't what they call you, it's what you answer to** (`0-whatsmyname.c`): Prints the program name from `argv[0]` followed by a new line.
* **1. Silence is argument carried out by other means** (`1-args.c`): Prints the count of arguments passed into the program (`argc - 1`).
* **2. The best argument against democracy is a five-minute conversation with the average voter** (`2-args.c`): Prints every argument in `argv` from index `0` to `argc - 1`, one per line.
