# 0x0A. C - argc, argv
* **0. It ain't what they call you, it's what you answer to** (`0-whatsmyname.c`): Prints the program name from `argv[0]` followed by a new line.
* **1. Silence is argument carried out by other means** (`1-args.c`): Prints the count of arguments passed into the program (`argc - 1`).
* **2. The best argument against democracy is a five-minute conversation with the average voter** (`2-args.c`): Prints every argument in `argv` from index `0` to `argc - 1`, one per line.
* **3. Neither irony nor sarcasm is argument** (`3-mul.c`): Multiplies two integer arguments and prints the result, or prints `Error` and returns `1` if the argument count is wrong.
* **4. To infinity and beyond** (`4-add.c`): Adds positive integer arguments, prints `0` when none are passed, and prints `Error` returning `1` on non-digit characters.
* **5. Minimal Number of Coins for Change** (`100-change.c`): Computes the minimum number of coins (`25`, `10`, `5`, `2`, `1`) for a given cent amount.
