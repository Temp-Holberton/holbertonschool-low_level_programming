# 0x0b. C - more malloc, free
* **0. Trust no one** (`0-malloc_checked.c`): A function that allocates memory using `malloc` and exits with status `98` if it fails.
* **1. string_nconcat** (`1-string_nconcat.c`): A function that concatenates two strings up to `n` bytes of the second string.
* **2. _calloc** (`2-calloc.c`): A function that allocates zero-initialized memory for an array using `malloc`.
