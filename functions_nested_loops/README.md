# Project: 0x02. C - Functions, nested loops

A foundational project exploring nested loops, functions, header files, and custom standard library implementations like `_putchar` in C.

## Tasks

- **0-putchar.c**: A C program that prints `_putchar` followed by a new line using a custom `_putchar` function.
- **1-alphabet.c**: A function that prints the alphabet in lowercase followed by a new line, using `_putchar` exactly twice.
- **2-print_alphabet_x10.c**: A function that prints the lowercase alphabet 10 times using nested loops and `_putchar` exactly twice.
- **2-print_alphabet_x10.c**: A function that prints the lowercase alphabet 10 times using nested loops and `_putchar` exactly twice.
- **3-islower.c**: A function that checks for lowercase characters, returning 1 if true and 0 otherwise.
- **4-isalpha.c**: A function that checks for alphabetic characters (lowercase and uppercase), returning 1 if true and 0 otherwise.
- **5-sign.c**: A function that prints the sign of a number (`+`, `0`, `-`) and returns `1`, `0`, or `-1`.
- **6-abs.c**: A function that computes the absolute value of an integer.
- **7-print_last_digit.c**: A function that prints and returns the last digit of a number.
- **8-24_hours.c**: A function that prints every minute of the day from 00:00 to 23:59.
- **9-times_table.c**: A function that prints the 9 times table starting from 0 with correct column spacing.
- **10-add.c**: A function that adds two integers and returns the result.
- **11-print_to_98.c**: A function that prints all integers from n to 98 in ascending or descending order.
