# Project: intro_debugging

A practical debugging module focused on identifying and fixing logic errors in C programs using step-by-step tracing.

## Tasks

- **sum_to_n.c**: Fixed off-by-one loop bounds and return value bugs to correctly compute the sum of numbers from 1 to n.
- **multiplication_table.c**: Fixed double-incrementing loop control variable (`col++`) inside the inner loop to correctly print all multiplication products.
- **row_sums.c**: Fixed variable accumulation bug by changing `current +=` to `current =` inside the outer loop to correctly compute row sum totals.
