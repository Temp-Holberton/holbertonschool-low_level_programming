# Project: more_functions_nested_loops

A continuation of C programming fundamentals focusing on nested loops, functions, and stricter modular design.

## Tasks

- **0-isupper.c**: A function that checks for uppercase characters.
- **1-isdigit.c**: A function that checks for digit characters (0 through 9).
- **2-mul.c**: A function that multiplies two integers and returns the product.
- **3-print_numbers.c**: A function that prints numbers from 0 to 9 using `_putchar` twice.
- **4-print_most_numbers.c**: A function that prints numbers from 0 to 9 excluding 2 and 4.
- **5-more_numbers.c**: A function that prints 10 times the numbers from 0 to 14 using `_putchar` three times.
- **6-print_line.c**: A function that draws a straight line using underscores in the terminal.
- **7-print_diagonal.c**: A function that draws a diagonal line using backslashes and spaces in the terminal.
- **8-print_square.c**: A function that prints a square of '#' characters given a specified size.
