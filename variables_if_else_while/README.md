# Project: 0x01. C - Variables, if, else, while

A foundational project exploring C control structures, conditional statements (if, else), relational/logical operators, and basic loops.

## Tasks

- **0-positive_or_negative.c**: A C program that assigns a randomly generated number to a variable `n` and prints whether the number is positive, zero, or negative, followed by a new line.
- **1-last_digit.c**: A C program that assigns a random number to `n`, prints its last digit, and evaluates whether it is greater than 5, zero, or less than 6 and not zero.
- **2-print_alphabet.c**: A C program that prints the lowercase alphabet from `a` to `z` followed by a new line using the `putchar` function exactly twice.
- **3-print_alphabets.c**: A C program that prints the alphabet in lowercase followed by uppercase, ending with a new line, using `putchar` exactly three times.
- **4-print_alphabt.c**: A C program that prints the lowercase alphabet excluding 'e' and 'q', followed by a new line, using `putchar` exactly twice.
- **5-print_numbers.c**: A C program that prints all single-digit numbers of base 10 starting from 0, followed by a new line.
- **6-print_numberz.c**: A C program that prints all single-digit base 10 numbers using `int` variables only and `putchar` exactly twice.
- **7-print_tebahpla.c**: A C program that prints the lowercase alphabet in reverse order (`z` to `a`) followed by a new line, using `putchar` exactly twice.
- **8-print_base16.c**: A C program that prints all numbers of base 16 in lowercase (`0-9`, `a-f`) followed by a new line, using `putchar` exactly three times.
- **9-print_comb.c**: A C program that prints all single-digit number combinations separated by `, ` using only `int` variables and `putchar` four times maximum.
