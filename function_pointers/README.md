# 0x0E. C - Function pointers
* **0. What's my name** (`0-print_name.c`): Invokes a callback function pointer to print a name.
* **1. If you spend too much time thinking about a thing, you'll never get it done** (`1-array_iterator.c`): Applies a callback function to each element of an integer array.
* **2. To hell with circumstances; I create opportunities** (`2-int_index.c`): Searches an integer array for the first element matching a callback predicate.
